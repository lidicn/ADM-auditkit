### 2. outbound 规则版本冲突 —— 裁决：**Qoder 版胜**

对拍方法：同一目标（doubao-butler，966 py / 173k 行）同一条规则跑两轮定向审计。

| 版本 | 字节 | md5 | 命中 |

| A CodeBuddy 版 | 5,581 B | `29ef26afbea0` | **21** |
| B Qoder 版 | 9,367 B | `45d256c1a8ff` | **20** |

- 共同命中 20 条；**A 独有 1 条，B 独有 0 条** —— Qoder 版是 CodeBuddy 版的严格子集
- A 独有的那 1 条 = `tests/test_llm_retry.py:31` 的 `httpx.Request("POST", "http://test/v1/chat/completions")`：**测试桩构造，不是外部调用，是假阳性**。根因是 CodeBuddy 版把方法名 lower() 后按 HTTP 动词词根匹配，`Request` 被误判为 `request` 动词；Qoder 版对 `get` 收紧为「receiver 整名等于客户端词」，大小写口径也规避了该形态
- 处置：**统一采用 Qoder 版**（本地已覆盖为该版，容器本来就是该版，双向一致）；CodeBuddy 版归档至 `经验/归档/py_outbound_call_no_timeout.codebuddy_5581.py.bak` 备查
